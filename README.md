# 메이플스토리 길드 스케줄

길드 주간 가능 시간표 · 확정 파티 일정 · 파티 구함 게시판을 한 화면에서 관리하는 웹 앱입니다.

- 주간 가능 시간표: 길드원별 요일/시간대 참여 가능 시간을 클릭해서 등록 (닉네임 표시)
- 확정 파티 일정: 고정 파티원이 자동으로 매칭되어 일정 확정
- 파티 구함 게시판: 모집 글 작성·참여
- 모든 데이터는 브라우저(localStorage)에 저장되며 서버로 전송되지 않습니다.

## 사용

https://seorinkong-hue.github.io/maple-guild-scheduler/

모바일 사파리에서 열고 **공유 → 홈 화면에 추가**하면 앱처럼 실행됩니다.
