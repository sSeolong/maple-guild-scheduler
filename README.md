# 메이플스토리 길드 스케줄

길드 주간 가능 시간표 · 고정 파티 자동 매칭 · 파티 구함 게시판을 한 화면에서 관리하는 웹 앱입니다.

## v6에서 달라진 점 — 실시간 동기화

- **길드 공용 데이터가 Firebase Realtime Database에 저장됩니다.** 같은 주소를 연 길드원이면 누구든 같은 시간표·파티·모집 글을 봅니다.
  길드원 · 고정 파티 · 확정 파티 · 모집 글 · 가능 시간이 공유 대상입니다.
- **가능 시간은 한 칸 단위로 저장됩니다** (`/guild/v1/availability/{주}/{길드원}/{칸}`).
  두 사람이 같은 순간에 서로 다른 칸을 눌러도 서로의 체크를 덮어쓰지 않습니다.
- **내 캐릭터와 세팅 접힘 상태는 이 기기에만** 저장됩니다. 남의 화면에서 내 캐릭터가 바뀌지 않습니다.
- 헤더에 상태 표시가 생겼습니다: `🟢 실시간 동기화` / `🔄 연결 중...` / `⚠️ 오프라인 (로컬)`.
  연결이 끊기면 이 브라우저(localStorage)에 저장해 두었다가 다시 연결될 때 올립니다.
- 처음 연 데이터베이스가 비어 있을 때만 샘플 데이터를 올립니다. 이미 길드가 쓰고 있는 데이터는 샘플로 덮지 않습니다.
- `샘플 데이터로 되돌리기` / `샘플 비우고 빈 상태로`는 확인 창을 거쳐 **길드 전원에게 함께** 적용됩니다.

## v5에서 달라진 점

- **캘린더 일정 제목**: 내보내는 일정 제목이 `오늘은 보스 ○○ 가는 날 입니다` 형식으로 바뀌었습니다. `.ics` 파일(SUMMARY)과 구글 캘린더 링크(text) 둘 다 같습니다.
- **기본 알림 1시간 전**: '당일 아침 알림' 시간 입력 대신 **알림** 선택으로 바뀌었고 기본값이 **1시간 전**입니다.
  선택지는 10분 전 / 30분 전 / **1시간 전(기본)** / 2시간 전 / 3시간 전 / 당일 아침 09:00 / 알림 없음.
  `.ics`에는 `VALARM` + `TRIGGER:-PT60M`(시작 1시간 전)이 들어가고, '당일 아침 09:00'을 고르면 그 시각에 울리도록 절대 시각으로 들어갑니다. 구글 캘린더 링크는 알림을 직접 넣을 수 없어 일정 설명에 알림 시각을 적어 둡니다.
- 기존에 저장해 둔 파티의 아침 알림 설정은 1시간 전으로 옮겨집니다.

## v4에서 달라진 점

- **오전 칸 추가**: 시간표 맨 앞에 **오전** 칸이 생겼습니다. 시간을 10~12시로 못 박지 않고 '오전 중 가능'만 표시합니다. 주말 낮에 잠깐 가능한 날도 표시해 두세요.
  (실제 시간이 필요한 곳 — '이 시간으로 파티 만들기'의 시작 시간과 .ics/구글 캘린더 내보내기 — 은 10:00 KST가 기본값이고, 파티 폼에서 원하는 시간으로 바꿀 수 있습니다.)
- **보스 리셋 주간**: 주간 기준을 월~일에서 **목~수**(목요일 보스 리셋)로 바꿨습니다.
  요일 순서는 목·금·토·일·월·화·수이고, '이번 주'는 현재 목~수 보스 주간입니다(예: 11/12(목)~11/18(수)).
- 기존에 저장해 둔 가능 시간은 실제 날짜를 기준으로 옮겨서 새 주간에 그대로 남습니다(v3 → v4 자동 마이그레이션).

## v3에서 달라진 점

- **초기 세팅**: 길드원을 쉼표로 한 번에 추가하고, 고정 파티마다 **보스를 여러 개** 고를 수 있습니다.
  예) 1팟 = A·B → 세렌·칼로스 / 2팟 = B·C·D → 림보·흉성
- **내 캐릭터**: 한 번 지정해 두면 다음 방문부터 자동으로 선택되어, 가능한 시간 칸만 누르면 됩니다.
  세팅은 저장 후 접혀서 상단에 요약(내 캐릭터 · 길드원 수 · 고정 파티 수)만 남습니다.
- **합집합 테두리**: 길드 전체 가능 시간표에서
  - 고정 파티 전원이 모이는 칸 → 그 파티 색 테두리 + 색 점
  - 두 파티 이상 동시에 가능한 칸 → 이중 테두리 + 바깥 점선(합집합)
  - 두 파티에 모두 속한 파티원(예: B) → 칸 안에서 주황색으로 표시
- **합집합 목록**: '확정 파티 일정' 탭에서 두 파티가 겹치는 시간과 겹치는 파티원을 모아 보여 줍니다.
  파티원이 겹치지 않으면 "동시 진행 가능"으로 표시합니다.
- **겹침 방지**: 같은 시간에 이미 확정된 파티와 파티원이 겹치면 확정을 막고 누가 겹치는지 알려 줍니다.
  (겹치는 사람이 없으면 두 파티를 같은 시간에 잡을 수 있습니다.)

## 사용

https://sseolong.github.io/maple-guild-scheduler/

모바일 사파리에서 열고 **공유 → 홈 화면에 추가**하면 앱처럼 실행됩니다.
길드 공용 데이터는 Firebase Realtime Database(`maple-guild` 프로젝트, `/guild/v1`)에 저장되고,
내 캐릭터·세팅 접힘 상태만 브라우저(localStorage)에 남습니다.
