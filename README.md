# 메이플스토리 길드 스케줄

길드 주간 가능 시간표 · 고정 파티 자동 매칭 · 파티 구함 게시판을 한 화면에서 관리하는 웹 앱입니다.

## v18에서 달라진 점 — 상단 `❓ 사용법` 버튼

- 헤더의 실시간 연결 상태 줄 옆에 **`❓ 사용법` 버튼**을 넣었습니다. 390px 모바일 첫 화면에서 바로 보이고 누를 수 있습니다.
- 누르면 **길드원용 사용설명서**가 뜹니다(5단계).
  1. 처음 들어왔을 때 (초기 세팅) — `펼치기`/`세팅 수정`, 길드원 추가, `내 캐릭터` 지정, 고정 파티·목표 보스 등록
  2. 내 가능 시간 입력하기 — 닉네임 고르고 칸 체크, 카톡 붙여넣기, `00-02시` 기준
  3. 길드 전체 시간 확인 & 파티 확정 — 파티 테두리, `이 팟으로 확정`
  4. 확정 일정 확인 & 캘린더 알림 — `1시간 알림 캘린더 추가`, `카톡 메시지 복사`
  5. 파티 구할 때 — 모집 글 올리기, 신청 댓글
- 안내 문장은 한 문장 = 한 줄(마침표 기준 줄바꿈)로 적었습니다.
- 닫기: 아래 `확인했어요` 버튼, 배경 탭, `ESC`. 내용이 길면 안내 칸을 위로 밀어 4·5단계까지 볼 수 있습니다.

## v17에서 달라진 점 — `00-02시` 칸이 각 날짜의 맨 앞으로

- 하루 칸 순서가 **`00-02시` → `오전` → `6~8시` → `8~10시` → `10~12시(자정까지)`** 로 바뀌었습니다.
- **`00-02시`는 그 날의 00:00** 입니다. 목요일 `00-02시` = 목요일 00시(보스 리셋 직후), 수요일 `00-02시` = 수요일 00시(리셋 전 밤).
  - 예전에는 `자정 이후` 칸이 그 날 24:00 = **다음 날** 00:00 이라 헷갈렸습니다. 이제 날짜를 넘기는 처리가 없습니다.
- 예전에 체크해 둔 `자정 이후` 값은 **실제 시각 그대로 다음 날 `00-02시` 칸으로 자동 이동**합니다(예: 예전 `목 자정 이후` → 새 `금 00-02시`).
- 카톡 붙여넣기: `목 00시` · `자정` · `새벽 1시` → **그 날 `00-02시`** 칸으로 들어갑니다.
- 확정 파티: `11월 19일 00:00` 파티는 **목요일 `00-02시`** 칸에 표시되고, `.ics`도 11/19 00:00 그대로 들어갑니다.

## v16에서 달라진 점 — 안내 문구를 문장 단위로 줄바꿈

- 모든 창(탭·카드·폼·모달)의 **설명·도움말 문구를 마침표(`.`) 기준으로 줄바꿈**했습니다. 한 문장이 끝나면 다음 줄에서 시작합니다.
  - 대상: 초기 세팅·카톡 붙여넣기·가능 시간 입력·길드 전체 가능 시간·확정 파티 캘린더·확정된 파티·자동 매칭·직접 추가 폼·파티 구함·모집 글 폼·비어 있음/지난 주 안내·시간 변경 확인 모달·바닥글
- `·` 로 이어 붙던 두 안내(캘린더 추가 / 카톡 복사, 캘린더 범례)도 **한 줄에 하나씩**으로 나눴습니다.
- 줄 간격을 `1.5` → `1.7`(작은 안내는 `1.6~1.65`)로 넓혀 390px 모바일에서 문장 경계가 잘 보입니다.
- 길드원 닉네임·메모·보스 이름 같은 **사용자가 넣은 값은 그대로**입니다. `모집중 4개 · 전체 5개 …` 처럼 한 줄 상태 표시도 그대로입니다.

## v15에서 달라진 점 — 확정 카드 버튼: `1시간 알림 캘린더 추가` · `카톡 메시지 복사`

- **확정된 파티 카드의 버튼이 두 개로 정리**되었습니다. (`애플 캘린더 (.ics)` · `구글 캘린더` → 아래 두 개)
  - **`📅 1시간 알림 캘린더 추가`** — 캘린더 파일(.ics)을 내려받아 **아이폰 · 갤럭시 · 구글 캘린더** 어디에나 넣을 수 있습니다.
    파일 안에 `VALARM`(1시간 전)이 들어 있어 **파티 시작 1시간 전에 알림**이 울립니다.
    카드에서 고른 알림이 1시간이 아니면 버튼 문구도 `30분 전 알림 캘린더 추가` · `2시간 알림 캘린더 추가` · `아침 9시 알림 캘린더 추가` 처럼 그 알림으로 바뀌고, `알림 없음` 이면 `📅 캘린더에 추가` 가 됩니다. 파일에 들어가는 알림도 같은 값입니다.
  - **`📋 카톡 메시지 복사`** — 단톡방에 그대로 붙여넣을 공지 문구를 복사합니다.
    `[보스 일정 확정] 노말 발드릭스` / `📅 11월 18일 (수) 20:00 시작` / `👥 서롱, 까오밥` / `🔗 https://sseolong.github.io/maple-guild-scheduler/`
    복사하면 `카톡 공지 메시지를 복사했어요! 단톡방에 붙여넣기 하세요` 토스트가 뜹니다. (iOS 사파리에서도 복사되도록 예비 경로를 둡니다.)
- `확정된 파티` 제목 아래에 이 두 버튼이 어떻게 동작하는지 한 줄 안내가 붙습니다.

## v14에서 달라진 점 — 같은 고정 파티는 한 주에 하나만 · 시간 변경 확인

- **같은 고정 파티를 같은 보스 주(목~수)에 두 번 확정해도 중복으로 쌓이지 않습니다.**
  `이 팟으로 확정`(칸 상세)과 `이 날짜로 확정하기`(고정 파티 자동 매칭)가 **같은 확인 절차**를 거칩니다.
- **이미 그 시간에 확정되어 있으면**: 새로 만들지 않고 `이미 11월 18일 (수) 22:00에 확정된 파티예요` 안내만 보여 줍니다.
  칸 상세의 버튼도 `✅ 이 시간으로 확정됨` 으로 바뀌어 눌러도 중복이 생기지 않습니다.
- **같은 주의 다른 날짜·시간을 누르면**: 확인 창이 뜹니다 —
  `이미 도적떼 파티가 11월 18일 (수) 22:00 (오후 10시~자정)에 확정되어 있습니다.` /
  `11월 18일 (수) 20:00 (오후 8~10시)으로 시간을 변경할까요?`
  → **`시간 변경하기`** 를 누르면 기존 확정 **하나의 날짜·시각만** 옮기고(파티가 늘지 않음), 적어 둔 보스 이름·파티원·메모는 그대로 둡니다.
  → **`그대로 두기`** 를 누르면 아무 것도 바뀌지 않습니다. 버튼이 애매하지 않도록 `🔄 이 시간으로 변경` 으로 미리 표시됩니다.
- 확정 파티 카드 목록과 `확정 파티 주간 캘린더` 에는 **옮겨진 시간 하나만** 남습니다. 고정 파티 카드에는 `✅ 이번 주 확정 · 11/18 22:00` 배지가 붙습니다.
- **보스 주가 다르면(예: 다음 주) 그대로 새로 확정**됩니다. 주당 하나라는 규칙은 목~수 한 주 안에서만 적용됩니다.
- 이전에 이미 중복으로 만들어진 확정 파티는 지우지 않습니다. 같은 시간을 다시 눌러도 더 늘지 않고, 확인 창에서 그중 하나만 옮깁니다(안내 문구에 `이번 주에 N개` 표시).

## v13에서 달라진 점 — 보스 종류 필터 · 실시간 신청 댓글 · 서버 덮어쓰기 방지

- **파티 구함 위 `보스` 필터가 난이도 없는 보스 종류 전체**로 바뀌었습니다:
  `전체 보스 · 세렌 · 칼로스 · 카링 · 림보 · 흉성 · 벨로나 · 스우 · 발드릭스 · 검은마법사`.
  `하드 세렌` · `익스트림 세렌`처럼 난이도가 붙은 글도 **`세렌` 하나로** 걸립니다.
  지금 올라온 글에만 있는 `그외` 보스(예: `하드 윌` → `윌`)는 목록 뒤에 자동으로 붙고, 그 글이 사라지면 함께 사라집니다.
- **모집 글 올리기의 `연락처 / 디스코드` 칸을 없앴습니다.** 신청은 이제 카드 안에서 바로 받습니다.
  (예전 글에 저장된 연락처 값은 지우지 않고 카드에 그대로 보여 줍니다.)
- **모든 모집 카드에 `💬 신청 댓글` 칸**: 댓글이 `닉네임 · 내용 · 11/18 18:15 · ×` 순서로 시간순으로 쌓이고,
  카드 안에서 `닉네임`(내 캐릭터로 자동 채움, 수정 가능) + `메시지` + **`신청 / 댓글 달기`** 로 바로 남깁니다. Enter 로도 등록됩니다.
  댓글을 지울 때는 `×` 를 누르고 한 번 확인하며, 모집 글을 삭제하면 그 글의 댓글도 함께 지워집니다.
- **댓글은 Firebase `/guild/v1/recruits/{글}/comments/{댓글}` 에 잎(leaf) 단위 `update()` 로만 씁니다.**
  두 사람이 같은 글에 동시에 신청해도 서로의 글·다른 칸·다른 댓글을 덮어쓰지 않고, 다른 기기의 댓글이 실시간으로 나타납니다.
  글을 수정해도 댓글은 그대로 남습니다.
- **서버 덮어쓰기 사고 방지**: 첫 접속 때 서버(`/guild/v1`)에 **값이 하나라도 있으면 절대 쓰지 않고 읽어서 맞추기만** 합니다.
  시드는 ① 연결이 확인되고 ② 두 번째 읽기에서도 비어 있을 때만 합니다. → 낡은 화면(옛 탭)이 서버를 통째로 덮어쓰던 문제를 막습니다.

## v12에서 달라진 점 — 파티 구함도 보스 2단계 선택 · 직업 칸 제거

- **파티 구함 모집 글의 목표 보스도 `보스 → 난이도` 2단계 선택기**로 골랐습니다(초기 세팅의 고정 파티와 같은 선택기).
  `세렌 · 칼로스 · 카링 · 림보 · 흉성 · 벨로나 · 스우 · 발드릭스 · 검은마법사 · ＋그외` 중 보스를 누르면 그 보스의 난이도만 펼쳐지고,
  난이도를 누르면 `하드 세렌`처럼 추가됩니다. **여러 개**를 고를 수 있고, 난이도가 하나뿐인 스우 · 검은마법사는 한 번에 골라집니다.
- 고른 보스는 `선택한 보스 N` 목록에 `하드 세렌 ×` 로 보이며 `×`로 뺄 수 있습니다. **그외**는 보스 이름을 직접 적어 추가합니다(쉼표로 여러 개).
- **모집 카드에는 고른 보스가 하나씩 배지로** 나옵니다(예: `하드 세렌` `카오스 칼로스` `노말 흉성`).
  위의 **보스 필터**도 이제 보스 하나하나(예: `하드 루시드`)로 걸러, 그 보스를 목표로 한 글만 보여 줍니다.
- **직업 입력칸과 직업 배지를 없앴습니다**: 모집 글 올리기 폼은 `닉네임 / 파티명 · 스펙 / 환산 · 목표 보스 · 구하는 포지션/조건 · 연락처 · 한 줄 메모`만 남았고,
  필터에서도 직업을 뺐습니다. 예전에 올린 글의 직업 값은 지우지 않고 저장된 그대로만 두어(화면에는 안 보임) 데이터가 사라지지 않습니다.
- 목표 보스를 여러 개 담아도 저장 구조는 그대로 `boss: "하드 세렌 · 카오스 칼로스"` 한 칸이라, 예전 글도 그대로 읽히고 Firebase 데이터를 손보지 않습니다.

## v11에서 달라진 점 — 확정 파티 전용 주간 캘린더

- **`확정 파티 일정` 탭 맨 위에 `확정 파티 주간 캘린더`**: 목~수 · 5시간대(오전 · 6~8 · 8~10 · 10~자정 · 자정 이후) 표에
  **확정된 파티만** 모아 보여 줍니다. 카드 오른쪽에 `‹ · 이번 주 · 다음 주 · ›` 와 날짜 범위(`11/19~11/25`)가 붙어 있고,
  위쪽 주간 바·`길드 전체 가능 시간` 카드와 **같은 주**를 가리킵니다.
- **칸 표시**: 파티가 **시작하는 칸**은 고정 파티 색 띠 + 파티 이름 + 시작~끝 시각(`20:00–06:00`)으로 진하게,
  600분짜리처럼 **이어지는 칸**은 `↳` 와 옅은 테두리로 표시합니다. 파티가 걸친 칸에는 한 번씩만 나오고,
  한 칸에 여러 개면 `+N` 으로 접습니다(휴대폰은 2개까지).
- **칸을 누르면** 아래 `확정된 파티` 카드로 이동해 잠깐 초록 테두리로 강조합니다. 캘린더 내보내기(.ics·구글)는 그 카드에서 그대로 합니다.
- **보고 있는 주에 확정 파티가 없으면** `다음 주(11/19~11/25) 보기 →` 버튼을 같이 보여 줍니다.
- **`길드 전체 가능 시간` 칸은 다시 깔끔하게**: v10에서 칸 맨 아래 붙던 초록 확정 파티 배지(`✅고장난손가락`)를 없앴습니다.
  확정 파티는 전용 캘린더에서 보고, 시간표 칸은 가능 인원·고정 파티 테두리만 봅니다. 칸을 누르면 상세의 `✅ 이미 확정된 파티` 안내는 그대로 남습니다.

## v10에서 달라진 점 — 카드 안 주 전환 · 확정 파티 배지 · 화면 순서

- **`길드 전체 가능 시간` 카드 안에 주 전환 버튼**: 카드 제목 오른쪽(휴대폰은 제목 아래 한 줄)에
  `‹ · 이번 주 · 다음 주 · ›` 와 지금 보고 있는 주의 날짜 범위(`11/19~11/25`)가 붙었습니다.
  아래쪽에서 시간표를 보다가 페이지를 위로 올리지 않고 바로 다음 주로 넘어갈 수 있고,
  위쪽 주간 바와 **같은 주**를 가리킵니다(버튼을 눌러도 화면이 위로 튀지 않습니다).
- **확정 파티 배지**(v11에서 전용 캘린더로 옮겼습니다): `길드 전체 가능 시간` 칸 **맨 아래**에 그 날짜·시간에 이미 잡힌 확정 파티가
  초록 배지(`✅고장난손가락`, 모바일 `✓고장난손가락`)로 보였습니다. 같은 칸에 여러 개면 `+1`처럼 개수를 붙였습니다.
- **`확정 파티 일정` 탭 순서**: `확정된 파티`가 맨 위, `고정 파티 자동 매칭`이 그 아래로 바뀌었습니다.
- **확정 알림 문구**: 자동 매칭으로 확정하면 `…로 확정했어요! '확정 파티 일정'에서 확인해 주세요`로 안내합니다.

## v9에서 달라진 점 — 초기 세팅 기본 접힘 · 카톡 칸 위로 · 보스 → 난이도 2단계

- **초기 세팅은 창을 열면 항상 접힌 채로** 시작합니다. 상단에 `내 캐릭터 · 길드원 N명 · 고정 파티 N개` 요약과 **세팅 수정** 버튼만 보입니다.
- **📋 카톡 채팅 붙여넣어 자동 입력** 카드를 **가능 시간 입력** 위로 올렸습니다. 시간표를 채우는 순서(카톡 붙여넣기 → 손으로 칸 누르기)대로 위에서 아래로 놓입니다.
- **목표 보스는 보스 → 난이도 2단계로 고릅니다.** 초기 세팅의 고정 파티 편집에서
  `세렌 · 칼로스 · 카링 · 림보 · 흉성 · 벨로나 · 스우 · 발드릭스 · 검은마법사 · 그외` 중 보스를 누르면
  바로 아래에 그 보스의 난이도만 펼쳐집니다(예: 칼로스 → 노말 · 카오스 · 익스트림). 난이도를 누르면 `하드 세렌`처럼 추가되고,
  난이도가 하나뿐인 **스우 · 검은마법사**는 보스를 한 번 누르면 바로 골라집니다.
- 고른 보스는 아래 **선택한 보스** 목록에 `하드 세렌 ×` 처럼 보이고, `×`로 하나씩 뺄 수 있습니다.
- **그외**를 누르면 보스 이름을 직접 적어 추가할 수 있습니다(쉼표로 여러 개).
- 예전에 저장된 보스 이름(`림보`, `세랜`처럼 난이도가 없거나 표기가 다른 값)도 그대로 남아 목록에 보이고 `×`로 정리할 수 있습니다.

## v8에서 달라진 점 — 지난 날짜 안내 · 다음 주로 바로 가기

- **모순 없는 자동 매칭 요약**: `이번 주 전원 가능` 목록이 **이미 지난 시간**뿐이면
  `이번 주 전원 가능 (이미 지남) · 목 10~자정 …` 처럼 **회색**으로 따로 보여 주고,
  아래 빈 칸에는 `이번 주에 겹친 시간(N개)은 이미 지난 날짜예요. 다가오는 주(11/19~11/25) 시간표에 입력해 보세요!` 라고 안내합니다.
- **📅 다음 주(11/19~) 시간표로 이동** 버튼: 지난 시간만 있어 확정할 게 없을 때 한 번에 다음 주 가능 시간표로 넘어갑니다.
- **주 선택 도움**: 이번 주가 거의 끝났거나(화·수) 지난 주를 보고 있으면 주간 바에
  `⏳ 이번 주(11/12~11/18)는 11월 18일 (수)까지예요` 안내와 **다음 주(11/19~) 보기** 버튼이 나오고,
  카톡 붙여넣기 칸 위에는 **어느 주 표에 들어가는지**(`📅 이번 주(11/12~11/18) 표에 들어갑니다`)가 항상 보입니다.
- **정리**: `합집합 — 두 파티가 같은 시간에` 카드와 `합집합` 배지를 없앴습니다. 두 파티가 겹치는 칸의 **이중 테두리**와 슬롯 상세의 **파티원 겹침 경고**는 그대로입니다.
- 가능 시간표 슬롯 상세에서 `⚔ 이 시간으로 파티 만들기` 버튼을 없애고, `이 팟으로 확정` 버튼을 주황색 기본 버튼으로 바꿨습니다.
  지난 시간의 칸을 고르면 `이미 지난 시간이에요` 안내가 함께 나옵니다.

## v7에서 달라진 점 — 카톡 채팅 붙여넣어 자동 입력

- **📋 카톡 채팅 붙여넣어 자동 입력** 카드가 생겼습니다 (가능 시간 입력 아래).
  카톡에서 복사한 글을 그대로 붙여넣으면 이름·요일·시간을 읽어 미리보기를 보여 주고,
  `✅ 표에 바로 반영`으로 Firebase에 칸 단위로 저장합니다. 여러 명이 한 번에 있어도 됩니다.
- 읽는 형식: `서롱 / 월,금,토 / 10시 이후` 같은 여러 줄, `서롱: 목,금,토 10시 이후 가능합니다` 같은 한 줄,
  `[서롱] [오후 9:12] …`, `서롱` + `오후 9:12` + 내용 같은 카톡 복사본(시간·날짜 머리글은 걸러 냅니다).
- 요일: 월~일(요일·콤마·공백·`/`·`·`), `주말`(토·일), `평일`(월~금), `매일`/`전부`(7일), `월~금` 범위.
- 시간: `오전`·`아침`→오전 칸 / `6시 이후`·`저녁`→6~8시부터 / `8시 이후`→8~10시부터 /
  `10시 이후`→**밤 10시**로 읽어 10시~자정·자정 이후 / `자정`·`새벽`·`12시 이후`→자정 이후 /
  `6~8시` 같은 범위와 `오후 8시`, `22:00` 표기도 읽습니다. 오전을 뜻한다면 `오전 10시`처럼 적어 주세요.
- 아직 없는 닉네임은 미리보기에 **(새 길드원 자동 추가)** 로 표시되고, 반영할 때 길드원으로 함께 등록됩니다.
  이름 없이 시간만 적혀 있으면 지금 선택한 **내 캐릭터**로 들어갑니다.
- 반영 방식은 **기존 시간 유지하고 추가**(기본) 또는 **해당 멤버 시간 덮어쓰기** 중에서 고를 수 있습니다.

## v6에서 달라진 점 — 실시간 동기화

- **길드 공용 데이터가 Firebase Realtime Database에 저장됩니다.** 같은 주소를 연 길드원이면 누구든 같은 시간표·파티·모집 글을 봅니다.
  길드원 · 고정 파티 · 확정 파티 · 모집 글 · 가능 시간이 공유 대상입니다.
- **가능 시간은 한 칸 단위로 저장됩니다** (`/guild/v1/availability/{주}/{길드원}/{칸}`).
  두 사람이 같은 순간에 서로 다른 칸을 눌러도 서로의 체크를 덮어쓰지 않습니다.
- **내 캐릭터와 세팅 접힘 상태는 이 기기에만** 저장됩니다. 남의 화면에서 내 캐릭터가 바뀌지 않습니다.
- 헤더에 상태 표시가 생겼습니다: `🟢 실시간 동기화` / `🔄 연결 중...` / `⚠️ 오프라인 (로컬)`.
  연결이 끊기면 이 브라우저(localStorage)에 저장해 두었다가 다시 연결될 때 올립니다.
- 처음 연 데이터베이스가 비어 있을 때만 샘플 데이터를 올립니다. 이미 길드가 쓰고 있는 데이터는 샘플로 덮지 않습니다.
- `샘플 데이터로 되돌리기` / `샘플 비우고 빈 상태로`는 확인 창을 거쳐 **길드 전원에게 함께** 적용됩니다.

## v5에서 달라진 점

- **캘린더 일정 제목**: 내보내는 일정 제목이 `오늘은 보스 ○○ 가는 날 입니다` 형식으로 바뀌었습니다. `.ics` 파일(SUMMARY)과 구글 캘린더 링크(text) 둘 다 같습니다.
- **기본 알림 1시간 전**: '당일 아침 알림' 시간 입력 대신 **알림** 선택으로 바뀌었고 기본값이 **1시간 전**입니다.
  선택지는 10분 전 / 30분 전 / **1시간 전(기본)** / 2시간 전 / 3시간 전 / 당일 아침 09:00 / 알림 없음.
  `.ics`에는 `VALARM` + `TRIGGER:-PT60M`(시작 1시간 전)이 들어가고, '당일 아침 09:00'을 고르면 그 시각에 울리도록 절대 시각으로 들어갑니다. 구글 캘린더 링크는 알림을 직접 넣을 수 없어 일정 설명에 알림 시각을 적어 둡니다.
- 기존에 저장해 둔 파티의 아침 알림 설정은 1시간 전으로 옮겨집니다.

## v4에서 달라진 점

- **오전 칸 추가**: 시간표 맨 앞에 **오전** 칸이 생겼습니다. 시간을 10~12시로 못 박지 않고 '오전 중 가능'만 표시합니다. 주말 낮에 잠깐 가능한 날도 표시해 두세요.
  (실제 시간이 필요한 곳 — 이 팟으로 확정과 .ics/구글 캘린더 내보내기 — 은 10:00 KST가 기본값이고, 확정된 일정은 파티 폼에서 원하는 시간으로 바꿀 수 있습니다.)
- **보스 리셋 주간**: 주간 기준을 월~일에서 **목~수**(목요일 보스 리셋)로 바꿨습니다.
  요일 순서는 목·금·토·일·월·화·수이고, '이번 주'는 현재 목~수 보스 주간입니다(예: 11/12(목)~11/18(수)).
- 기존에 저장해 둔 가능 시간은 실제 날짜를 기준으로 옮겨서 새 주간에 그대로 남습니다(v3 → v4 자동 마이그레이션).

## v3에서 달라진 점

- **초기 세팅**: 길드원을 쉼표로 한 번에 추가하고, 고정 파티마다 **보스를 여러 개** 고를 수 있습니다.
  예) 1팟 = A·B → 세렌·칼로스 / 2팟 = B·C·D → 림보·흉성
- **내 캐릭터**: 한 번 지정해 두면 다음 방문부터 자동으로 선택되어, 가능한 시간 칸만 누르면 됩니다.
  세팅은 저장 후 접혀서 상단에 요약(내 캐릭터 · 길드원 수 · 고정 파티 수)만 남습니다.
- **파티 테두리**: 길드 전체 가능 시간표에서
  - 고정 파티 전원이 모이는 칸 → 그 파티 색 테두리 + 색 점
  - 두 파티 이상 동시에 가능한 칸 → 이중 테두리
  - 두 파티에 모두 속한 파티원(예: B) → 칸 안에서 주황색으로 표시
- **겹침 방지**: 같은 시간에 이미 확정된 파티와 파티원이 겹치면 확정을 막고 누가 겹치는지 알려 줍니다.
  (겹치는 사람이 없으면 두 파티를 같은 시간에 잡을 수 있습니다.)
